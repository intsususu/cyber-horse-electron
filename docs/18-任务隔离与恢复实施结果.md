## 已实现的执行链

`WorkspaceTasks` 组织任务，`TaskProcessing` 执行所选步骤，`TaskScheduler` 分别管理 MDC、传输槽位，`TaskPublisher` 负责逐文件发布，`TaskRecovery` 负责用户确认后的核对与恢复。桌面不再用旧的公共媒体输出目录运行四步；旧执行器保留兼容与回归用途。

- 工作台与媒体库可同时提交，来源和状态独立；同一工作台运行中仍锁定所选步骤与文件范围，重复启动互斥。媒体库保持有界队列，复合任务内下载不重复计数。
- 任务目录位于已保存 `paths.download/.work/<任务>`。每个文件独立接管、处理和记账；字幕、视频输出、Jasna 临时媒体、MDC 输入和输出均在本文件子目录内。
- 同卷接管使用独占移交，跨卷校验复制后移除来源。复制的 NAS 旁车须在已保存根下且属于已批准影片清单。普通扫描、提取清理和直接文件选择排除整个 `.work` 与活动下载临时文件。
- 按用户要求取消 GPU 锁，Whisper 与 Jasna 跨任务可同时运行，并发由用户判断；不创建、等待或清理旧 GPU 占用记录，旧记录不阻止恢复。MDC 与传输仅在执行期间占用资源；等待可取消。来源与最终目标在进程内登记，共享下载根的不同应用配置通过磁盘资源记录协调槽位。遗留锁及仍引用任务路径的进程阻止接管。
- 无 NAS 归档的工作台结果发布回已保存预处理目录；有归档时保留 MDC 的影片结构，或使用识别到的番号目录。媒体库任务回写原影片目录。目标重名停止并保留任务，首版不自动产生新的影片文件夹后缀。
- 发布先保存目标、本地内容摘要和提交意图；NAS 完整上传、落盘、大小及最终身份快照持久化后才清理本地来源，不回读目标内容。NAS 替换清单只核对冻结的原文件元数据，整个新文件包通过后才清理旧名称文件；本地发布仍核对 SHA-256。部分提交可依据可靠快照继续，不承诺整批原子事务或回滚。
- MDC 标记、NFO、视频摘要或字幕旁车不符时，失败文件保留；其他成功文件可继续发布和归档。不会补写 NFO 伪造通过。

已保存下载、预处理目录，以及选归档时的 NAS 根必须有效；旧的字幕、视频、MDC 公共输出目录不再是新流程的必要条件。工具安装路径、模型和工具自身配置仍由用户维护。

## 用户确认恢复和移除

2026-10-01：永久删除完成且任务目录清理成功后，任务从列表和计数中消失，不进入“已完成”。内部移除摘要保留下载关联，重启后也不会重新出现独立下载；保留文件的历史继续可查。清理失败、仍活动或有可恢复目录的任务不隐藏，旧删除记录兼容展示规则。

关闭窗口与应用退出现在共用主进程确认：空闲也提示，有运行／排队／受理中的任务时明确警告，默认“继续使用”。取消不停止任务或关机计划；确认后拒绝新启动，取消关机计划，等待已受理文件操作和全部执行器收尾。收尾失败不强制关闭窗口，可再次尝试退出。

本轮定向验证：退出保护、任务视图、工作目录和统一任务四个测试文件共 70 项通过；生产构建（含类型检查）通过。`scripts/desktop-task-records.mjs` 验证单项删除取消／失败／成功、其他历史原样保留、刷新后不回到已完成及全局清空独立确认；已目视检查初号机主题删除后列表。`scripts/desktop-exit.mjs` 用隔离配置、本机文本下载与原生弹窗响应替身，验证空闲／运行中提示、重复关闭互斥、取消后下载继续及关机计划保留、应用退出入口拦截、确认后下载取消并保留临时文件。原生弹窗参数已断言，未做真实弹窗外观验收。桌面脚本收尾共用显式确认辅助方法，避免自动测试卡在新弹窗。未运行全量回归、真实媒体删除、真实关机或安装包验证，未重启用户当前应用。

启动只发现已登记根的有效任务，不自动执行外部工具。任务队列显示“未完成”残留，提供目录、原来源、步骤状态、已发布位置和执行记录。

恢复、保留和删除都先形成五分钟有效的预览，绑定任务修订号与文件快照；确认时重新核对文件、配置、目录和进程占用。重复确认、过期预览、文件变化、损坏记录和未知内容均拒绝执行。

恢复跳过已校验或已跳过步骤，未完成步骤在新的尝试目录中执行。输入移交前保存摘要和所属文件列表；MDC 移走输入后校验失败时，只允许从唯一摘要匹配的已登记产物重建输入。不能核对、存在歧义或缺少输入时停止，保留两端。

“结束并保留文件”先把已识别文件核对复制到下载根下的保留目录，全部通过后才逐项移除任务内来源；不覆盖同名目标。“永久删除任务文件”需要明确勾选可能删除唯一副本的确认，只删除预览中的已识别任务文件。未知文件阻断保留、删除和正常清理。“暂不处理”不操作文件。

清空记录只清除可结束的历史展示，不隐藏仍有目录的失败、取消或待恢复任务。任务目录只逐文件复核删除，再移除已确认为空的目录；不递归清理 `.work` 根或历史内部目录。

## Emby 收尾

媒体库任务记录服务器配置摘要和认证返回的服务器身份。回写后先通过 Emby 的 `Items` 接口按完整 `Path` 和当前 `UserId` 精确查询，再读取唯一项目的媒体源元数据核对路径、大小和所需中文字幕；通过后直接完成确认。改名后的新 ID 不依赖旧 ID，不再分页扫描全库；同路径多项目不猜测。

尚未匹配时才刷新已发现的新 ID；没有新 ID 时尝试原 ID，只有原 ID 已不存在的 404 可以继续等待。刷新请求提交不代表媒体更新完成；每 3 秒核对一次，整体确认上限 3 分钟；匹配后立即完成，刷新请求与等待均响应取消。超时保留最近一次未匹配原因。失败按路径未发现、大小不符、字幕未确认、歧义、权限或超时显示中文原因，保留任务清单，不显示第三方英文中止提示。“重试收尾”只重试服务器同步；用户也可明确结束服务器待确认。服务器配置变化或身份不符时不向新服务器同步历史任务。

完成摘要位于 `userData/workspace-tasks`，任务事件位于任务目录；脱敏工具输出每任务最多 2 MiB，界面内存日志有界。通过白名单提供任务列表、取消、操作预览、确认与按任务身份打开目录，渲染端不能指定任意文件路径或命令。
