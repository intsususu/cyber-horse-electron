## NAS 同名目录替换（2026-09-29）

- 工作台归档遇到同名 NAS 番号目录时，先将历史目录改名为同级 `_tmp`，再独占创建原目录名并写入、核对本次产物；完成后删除 `_tmp`。可识别番号统一使用原番号作为 NAS 文件夹名：`CJOD-392-C.mp4` 与视频破解后的 `CJOD-392-UC.mkv` 都归入 `CJOD-392`，视频文件名保持原样。演员父目录及其中其他番号、文件保留，只增量更新本次番号。此前已产生的后缀目录不会自动合并或删除。
- 预处理目录中的 MDC 回搬继续对同名目录另存，避免覆盖当前“目录全部”范围中尚待处理的视频；其 `_1` 序号不会传给可识别番号的 NAS 目标。复制失败时尝试恢复旧目录；已有 `_tmp`、本批多个视频指向同一 NAS 目录，或处理产物番号与原视频不符时停止，保留本地源文件。
- `npm run check` 通过 159 项测试、类型检查和生产构建；`npm run format:check`、`npm run test:desktop` 通过。隔离测试覆盖 `CJOD-392-C.mp4` 直接刮削、破解为 `CJOD-392-UC.mkv` 后刮削、已有 `CJOD-392-UC.mp4`、先改名 `_tmp` 再复制、演员目录保护、写入失败恢复旧目录、旧目录删除失败留待核对及同批目标冲突；已目视检查深色和浅色工作台截图，中文完整、面板未越界。真实网络 NAS 与断电时的替换提交未验证。
