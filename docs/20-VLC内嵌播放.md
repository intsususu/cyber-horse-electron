# 20 · VLC 内嵌播放

## 配置与范围

“偏好配置 → 媒体服务器 → 播放器”增加“使用 VLC 内嵌播放”和“检测 VLC”。配置保存在本应用的 `settings.json` 中，字段为 `player.useVlc`，旧配置自动补齐 `false`。保存后对下一次媒体库播放生效，关闭后继续使用 Chromium 播放器；字幕样式的合成预览仍使用原播放器。

当前面向 Windows x64，需要在标准安装位置安装 VLC 3.x 64 位版本。检测只检查原生宿主文件、DLL 架构与插件目录，实际打开视频时才加载并验证 libVLC 版本；检测通过不等于任何媒体均能播放。未安装、32 位、引擎启动失败或媒体解码失败时显示中文提示，可重试或关闭配置后使用默认播放器，不静默启动外部 VLC 窗口。

## 实现

- `src/shared/vlc-player.ts` 定义启动、状态、边界、暂停、定位、音量、字幕与关闭契约；预加载仅桥接这些固定能力。主进程检查调用来源、参数和已保存配置，不接受任意程序、文件路径或远程 URL。
- `native/vlc-host/Program.cs` 是独立的 Windows 原生宿主，通过系统 .NET Framework 编译器构建到 `out/native/vlc-host.exe`。运行时显式加载本机 VLC DLL，不使用 npm 原生插件，也不复制 VLC 安装文件。
- 宿主将视频输出绑定到 Electron 主窗口的子窗口，使用原生播放状态、时长、进度、解码尺寸和字幕轨。视频区域按窗口尺寸、系统缩放与页面缩放限制在应用内部。
- 返回与公共控制栏固定在画面外，防止 Windows 原生子窗口遮挡。字幕菜单展开时收缩原生视频区域，业务弹窗显示时隐藏原生区域；Chromium 播放器原有渐隐交互保持原样。
- 支持暂停、继续、前后 15 秒、进度定位、静音、音量、全屏与章节起点。原流中的字幕由 VLC 自己渲染，Emby 文字字幕可经本机代理以 WebVTT 添加；转换后的服务器字幕不承诺保留 ASS 样式。压在画面中的字幕仍无法独立关闭。
- 视频通过主进程的单会话回环代理转发，绑定 `127.0.0.1` 随机端口和随机能力地址，保留 Range 转发，拒绝其他路径、来源与写入请求。Emby 凭据和认证令牌不传给原生宿主或渲染端，不直接打开 NAS 文件，不修改视频，不参与下载、归档与发布链路。
- 关闭、切换页面、取消准备、渲染端崩溃与窗口退出撤销会话，关闭视频转发并停止宿主；正常退出超时后只终止本次创建的播放进程。旧会话关闭不能撤销较新的播放。
- Windows 开发和生产构建自动编译宿主；打包配置将其放入 `resources/vlc-host`，不打包 VLC 库。构建机需有系统 .NET Framework 编译器，目标电脑需有对应系统运行时和 64 位 VLC 3.x。

原生 API 依据：[VideoLAN libVLC 3.0 播放器接口](https://videolan.videolan.me/vlc-3.0/group__libvlc__media__player.html)。

## 本轮验证与限制

2026-10-01：`tests/vlc-player.test.ts`、`tests/settings.test.ts` 与 `tests/media-library.test.ts` 共 73 项定向测试通过，包含配置迁移、保存恢复、DLL 架构、参数与边界、视频与字幕白名单、取消、旧会话隔离和进程失败清理。TypeScript 检查、渲染产物构建和 Windows 宿主编译通过。

`scripts/desktop-vlc-playback.mjs` 使用隔离配置、替身 Emby 和生成的 90 秒、30 帧／秒测试片段，实际加载本机 libVLC，验证 320×180 解码、子窗口父级与可见状态、暂停、真实定位、静音开关、服务器字幕轨加载、默认与最小窗口、最大化、全屏 Esc、返回焦点及离页后宿主进程退出。当前主题为初号机；颜色令牌没有改动，不扩展为四主题全排列。普通网页截图只包含 Chromium 控件，原生画面另用系统合成截图目视核对，已显示测试画面与中文字幕。原来的 1 帧／秒合成片段在本机 VLC 中出现解码缓冲问题，不能据正常帧率用例宣称所有低帧率素材兼容。

`scripts/desktop-dev-playback.mjs` 验证默认播放器的开发模式跨域视频、字幕与旧后台兼容，通过。本轮未执行全量回归；真实 Emby 大文件、真实音频设备、多显示器与混合 DPI、完整安装包、签名及目标电脑部署仍待验证。已运行的旧主进程需要完整退出重启才能加载新增接口，不自动中断用户正在执行的媒体任务。
