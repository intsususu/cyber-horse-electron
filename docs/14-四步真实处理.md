# 14 · 四步真实处理

更新：2026-09-30。桌面工作台已接入 `.work` 独立任务执行，单步、部分组合与全部流程均按固定顺序运行。实现和验收边界见 [18 · 任务隔离与恢复实施结果](18-任务隔离与恢复实施结果.md)，方案依据见 [17 · 开发计划](17-任务工作目录与恢复开发计划.md)。独立预处理仍见 [13 · 提取清理并重命名](13-提取清理并重命名.md)。

## 运行与发布

工作目录默认使用已保存预处理目录。运行前生成十分钟有效的清单，冻结视频、同名旁车、选择范围与步骤；启动时复核配置、目录、文件和工具快照。空步骤、空选择、越界、链接及 `.work` 输入不能启动；开始后新增文件不加入批次，运行中不能修改步骤。

用户一次确认完整清单后，任务按字幕与封装、视频破解、元数据刮削、NAS 归档的顺序执行所选步骤，未选步骤不补跑。每个输入文件位于独立子目录，工具输入、输出、字幕和临时媒体均在其中。已保存下载根和预处理根必须有效；选 NAS 时还需有效 NAS 根，不再依赖旧的公共字幕、视频、MDC 输出目录。

未选归档时发布回预处理目录，MDC 的影片层级保留；选归档时发布 NAS。每文件分别校验和发布，本地目标核对 SHA-256；NAS 禁止回读内容，以完整写入、落盘、大小与持久化文件身份快照确认后才清理本地来源。重名目标停止，不覆盖未知文件。新流程不改名旧目录为 `_tmp`，也不自动接管历史 `_tmp` 或恢复目录。

MDC 单文件失败时保留失败输入／产物，其他通过校验的文件继续处理和归档，整批显示部分失败。取消、其他步骤失败或文件保护失败停止本任务；任务目录和记录保留，启动发现后由用户确认恢复或移除，不自动重跑。

## 工具和产物校验

| 步骤       | 调用和位置                                                                      | 成功条件                                                                                  |
| ---------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 字幕与封装 | Whisper `--output_dir` 指向任务字幕目录，mkvmerge 写任务输出                    | 有效 UTF-8 SRT、时间轴、时长和音轨正确；中文字幕轨校验；已有 C／UC 命名标记跳过并说明证据 |
| 视频破解   | Jasna 指定输入、输出、工作目录，关闭后处理命令与关机；mkvmerge 保留源音轨和字幕 | 视频结构、时长、音轨和原中文字幕保留；已有 U／UC／hack 标记跳过，不伪报工具执行           |
| MDC 刮削   | 单文件 `-cli`，任务内独立输入／输出，`--log-dir=`；不改共享配置                 | 视频 SHA-256 不变、番号与 C／U／UC 状态匹配、NFO 语义有效、封面非空、原字幕内容保留       |
| NAS 归档   | 异步单向上传，逐文件记账和元数据校验发布                                        | 完整写入、落盘、大小及身份快照确认后才清理；不回读 NAS，失败保留来源，不承诺整批原子提交  |

NFO 使用 XML 结构解析，禁止 DTD 和外部实体；“中文字幕”“破解”必须来自直接标签或分类，不从标题猜测，不自动补写标签。仅破解状态传给 MDC 时使用工具认可的 hack，重名防护不追加到规范标记后；规范名称和任务内映射分别保存。

ffprobe 在 Jasna、Whisper 或 MKVToolNix 同目录及 `tools` 子目录发现，不从任意 PATH 选择；mkvmerge 识别轨道，ffprobe 核对容器时长。工具帮助只验证参数，每次调用还检查可执行文件、源码、模型与依赖快照；帮助通过不代表 GPU、网络或登录有效。

Whisper 源码入口要求约定的 `infer.py`、配置、源码包、模型／VAD 和本目录虚拟环境。主进程以明确 Python 和参数数组运行，强制 UTF-8；GPU DLL 仅在子进程 PATH 中追加，库缺失或退出码 103 会给出中文提示并保留输入，不自动重建环境。其他入口使用明确可执行文件，不接受批处理，不经 shell。MDC 凭据仍由其自身配置管理，应用不导入凭据。

已有同名 SRT 会在任务内复制核对后复用；不存在时生成到任务字幕目录。ASS 转换保留中文和换行，最终字幕旁车随规范视频名发布。失败、中断和取消保留任务内登记文件；未知额外文件会阻断清理。

## 状态、进度与恢复

进度来自工具输出，不猜测无法解析的行。Whisper 按片段时间与媒体时长、Jasna 按帧处理输出、mkvmerge 按封装进度呈现当前阶段；准备、排队、校验和发布没有可靠百分比时使用未定进度。工具 100% 仍须退出码、产物校验和收尾通过。

日志只在任务队列展示，内存保留最近 200 条；工具输出每任务最多 2 MiB并脱敏。状态、来源移交、产物和发布事件保存到任务目录，完成历史和工具日志保存到应用数据目录。页面刷新恢复主进程状态，应用重启只发现残留，用户确认后只重跑未完成步骤。

取消停止受控进程树，哈希和传输在分块检查点响应；网络文件调用需等待系统返回。窗口关闭停止新调度并等待收尾，不执行真实关机。恢复、保留和删除的具体预览、文件保护与已发布结果核对见实施结果。

真实 Whisper／Jasna GPU 处理按用户要求暂缓，真实 NAS／Emby 联合验收和本轮打包／签名未执行。没有删除用户媒体或运行参考项目脚本。既有的旧布局与旧 NAS 大小校验测试用于兼容回归，不能代表新流程已完成上述实机验收。
