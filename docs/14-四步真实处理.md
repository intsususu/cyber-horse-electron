# 14 · 四步真实处理

日期：2026-09-27。工作台四步已经接入主进程文件服务和外部工具适配器；支持单步、部分组合及全部运行。原“标准流程”和“特殊任务”独立页面已移除。独立预处理见 [13 · 提取清理并重命名](13-提取清理并重命名.md)。

## 运行方式

工作目录默认跟随已保存的预处理目录，也可在已保存的下载、预处理、字幕工作、视频工作、MDC 输出、NAS 或媒体下载目录范围内选择子目录；拒绝配置范围之外的目录。运行前扫描并生成有效期十分钟的清单，展示视频、关联文件、执行顺序、输出位置和删除规则。启动时复核配置、目录和文件快照；预览后的新文件不进入任务。

四步默认全选，固定按 1 → 2 → 3 → 4 执行所选步骤。单步不改变组合，空步骤或空文件选择禁止批量运行。未选步骤不会自动补入；只选归档就复制当前范围已有的视频及相关文件，不自动刮削。工作台单步 MDC 成功后，当前工作目录恢复为预处理目录；“仅选中文件”范围跟随本次搬回的视频，随后可直接单步归档。

“运行全部”或运行部分组合只在启动前展示一次完整清单。用户确认后，所选步骤在同一任务中连续执行，步骤之间不再弹出应用确认框；失败或取消时停止后续步骤，并在任务队列记录结果。

下载、预处理、字幕工作、视频工作、MDC 输出和 NAS 目录需预先创建。参与执行的输出目录不得与源目录重叠。字幕和视频步骤直接读取源视频，在配置的工作目录写入中间输出，验证后同卷移动或跨卷校验复制回当前目录；随后删除被替换的旧视频和旧名称旁车。工作台 MDC 按单文件路径直接写入配置输出目录，校验后把本次产物复制并校验到预处理目录，再删除 MDC 输出目录中的对应文件；保留演员/番号层级，预处理目录中的同名目标文件夹仍另存，保护本次选择范围内尚待处理的文件。NAS 归档保留演员等父目录，对可识别的原视频番号统一使用不带 `-C`、`-U`、`-UC` 和回搬重名序号的番号目录；视频文件本身保留处理后的名称。处理产物若显示与原视频不同的番号则停止归档。同名番号目录先改名为 `_tmp`，在原目录名下复制新产物并校验，成功后只删除旧番号的 `_tmp` 目录；演员目录及其中其他番号、文件均保留。若 `_tmp` 已存在则停止，不自动覆盖或清理。无法识别番号时继续使用当前媒体文件夹名，或在根目录单文件归档时使用视频文件名。媒体库复合任务仍从 MDC 输出目录回写原 NAS 文件，不经过工作台的回搬。

## 工具与产物规则

| 步骤         | 工具及参数                                                                                           | 成功条件与命名                                                                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 字幕与封装 | Whisper 的 `--audio_suffixes`、`--sub_formats srt`、`--device cuda`；mkvmerge 指定中文轨道与默认字幕 | 有效 UTF-8 SRT、非空内容、时间轴不超出视频；按偏好保留 SRT 或生成 ASS 后封装。普通编号追加 `-C.mkv`，`-U` 改为 `-UC.mkv`；已有 `-C`/`-UC` 标记跳过 |
| 2 视频破解   | Jasna 的 `--input`、`--output`、`--working-directory`；明确关闭后处理命令及关机                      | 检查视频结构、时长与音轨；通过 mkvmerge 保留源音轨及字幕，输出 MKV。`-C` 改 `-UC`，普通编号追加 `-U`；已有 `-U`/`-UC` 标记跳过                     |
| 3 MDC 刮削   | MDC -cli 加单个视频路径，指定 source_folders、success_folder 和可选日志目录                          | 只统计本次新增产物；视频 SHA-256 与调用前输入一致，有有效 NFO、封面及非空产物；已有同名输出视频会阻止调用                                          |
| 4 NAS 归档   | 主进程异步单向文件复制                                                                               | 逐文件比对本地与 NAS 目标的文件大小；整批大小一致后直接删除对应本地文件，不回读 NAS 文件内容                                                       |

字幕/视频校验还需要 `ffprobe`。应用依次在已配置的 Jasna、Whisper、MKVToolNix 入口同目录和 `tools` 子目录寻找，不从系统 PATH 随意选取。Whisper 为源码目录时，从目录本身寻找。当前本机 Jasna 自带该工具，无需增加配置字段。mkvmerge 负责轨道识别，ffprobe 负责各容器的视频时长；不能假定 MP4 的 mkvmerge 识别结果提供时长。

预览通过 `--help` 验证所需命令行能力，每次调用前复核可执行文件和源码/模型文件快照。Whisper 可配置源码根目录，要求其中有 `infer.py`、`generation_config.json5`、`src/faster_whisper_transwithai_chickenrice`、`models` 中的模型及 VAD 文件，以及本目录 `.venv/Scripts/python.exe`。主进程以参数数组启动该 Python，传入 UTF-8 模式、模型路径及配置路径；不依赖系统 PATH 中的解释器，不通过 shell。其他工具仍需 `.exe`，不接受 `.bat`/`.cmd`。帮助检查不代表 GPU、模型、登录或网络服务可用。MDC 使用工具自身配置中的登录和云端设置，应用不导入这些凭据。

旧版 Whisper `infer.exe` 在 Windows GBK 环境下打印 `⚠️` 时会触发 `UnicodeEncodeError`。新版源码已设置标准输出和错误输出为 UTF-8；当前本机配置已改为源码目录，并建立独立 Python 3.10 虚拟环境，不再经过旧打包入口。旧 `.exe` 配置仍兼容，遇到相同错误时会提示并保留源文件。`--help` 在打印声明前退出，不能检出旧包故障。

若返回退出码 103 且输出 `No Python at`，应用会提示检查 `.venv/pyvenv.cfg` 的 `home` 指向及当前应用的访问权限；`.venv/Scripts/python.exe` 存在不代表基础解释器可用。推荐将基础 Python 放在工具目录内，再用它建立虚拟环境，避免依赖其他用户目录或可被清理的 uv 安装位置。应用不会自动下载 Python、调整权限或改写外部虚拟环境。能力检测失败不生成可运行清单；执行中失败停止后续步骤并保留源文件。

Windows 源码模式支持将匹配的 CUDA 12、cuDNN 9 动态库放在源码根目录的 `cuda/bin`。主进程仅为 Whisper 子进程追加该搜索目录，不修改系统 PATH，不依赖另一个工具的安装位置；目录中的 DLL 纳入预览快照，发生变化后须重新预览。缺少 cuBLAS、cuDNN 等库时显示具体库名和中文修复提示；帮助检查通过及模型加载完成都不代表实际 GPU 运算可用。安装匹配要求参见 [ONNX Runtime CUDA 文档](https://onnxruntime.ai/docs/execution-providers/CUDA-ExecutionProvider.html)。

字幕生成沿用参考项目的工具调用方式，字幕语言及翻译模型由 Whisper 自身配置决定。同名 SRT 已存在时先校验并复用，避免覆盖用户字幕；不存在时在源视频旁生成。SRT 转 ASS 保留中文和换行，使用微软雅黑。字幕和视频改名时同步复制并校验同名前缀旁车，成功后删除旧名称；通用封面沿用原路径。

ASS 模式只把本次生成的 ASS 用作封装输入，成功后清理生成的 ASS 和中间 SRT。已有字幕内容随新视频名称保留。失败或取消时清理本次已知中间输出，尚未成功替换的源视频保留；突然断电可能留下同目录中间文件，不自动将其当作媒体继续处理。

## 文件范围与清理

输入仅包括选中视频及同名 SRT、ASS、VTT、NFO、JPG、JPEG、PNG、WebP 与 poster/fanart/thumb。目录只有一个视频时可包含通用封面。MDC 使用单文件模式，不把整个输入目录作为批量处理目标；通过输出快照识别本次新增文件，不把已有其他影片加入后续归档。

不创建 .cyber-horse-work、.cyber-horse-recovery、media-task 或 .media-stage 任务目录，也不预先完整复制视频给工具。必要的中间产物和原子提交使用当前配置目录内的短期 .partial 文件，正常完成后清理。旧版本目录继续从扫描中排除，应用不会自动删除历史内容。

MDC 固定传入 `--log-dir=` 关闭工具文件日志；工具输出显示在队列及主进程控制台，不写入执行记录。应用计划、步骤、提交与删除事件仍写入应用数据目录。工作台的单次任务使用 `-cli` 和隐藏窗口启动；`-b` 是持续后台托管，会在完成后等待下次运行，不用于单次任务。

所有处理目录拒绝磁盘根、用户根、系统、项目、应用数据目录及路径中的符号链接和目录联接。复制、移动、删除均核对本次目录边界和文件快照；扫描跳过旧版本内部目录、未完成中间文件及带未完成标记的媒体包。只逐项删除清单文件和已知空目录，不递归清理工作根目录。

跨卷处理产物仍采用独占临时文件，分块计算 SHA-256，落盘后重新校验并提交到未占用的目标。同卷中间产物采用独占链接提交后移除原名称，避免再复制整片视频。NAS 首次归档在独占创建且带未完成标记的媒体目录中直接写入目标文件；同名番号目录已存在时，先标记并改名为同级 `_tmp`，再独占创建原目录名，直接写入新文件并核对大小。复制或校验失败时清理本次新目录并尝试将 `_tmp` 恢复原名；校验成功后逐项删除 `_tmp` 内文件及空目录，不递归删除演员目录。写入同步后只查询目标文件大小，不读取 NAS 文件内容，也不在 NAS 内二次复制。整批目标大小一致后才删除对应本地文件；复制失败、大小不符或磁盘满时保留本批本地输入。断电、恢复失败或旧目录清理中断可能留下 `_tmp`，下次归档会停止并要求人工核对；大小核对不能发现等长内容损坏。

字幕/视频产物验证成功后直接删除被替换的旧文件；MDC 搬回预处理目录时，整份产物提交并校验后才清理本次 MDC 输出；NAS 整批文件大小核对成功后逐项删除对应本地视频和相关文件。删除过程取消时，已完成删除不撤销，剩余文件留在原处。MDC 自身可能在调用中移动所选视频；失败时需要核对源目录、MDC 输出目录和预处理目录，不能承诺原路径仍存在。第三方工具按其自身配置运行，应用不提供文件系统沙箱或整批回滚。

## 状态、取消与日志

主进程统一互斥预处理和四步任务，包括预览和启动复核，不能同时操作文件。工具通过明确路径和参数数组运行，`shell: false`、隐藏窗口；采集输出和退出码，常见凭据及 URL 查询串脱敏。工具处理默认最长 24 小时，MDC 最长 2 小时，能力/结构检查最长 60 秒。

任务保留已完成文件数（包括跳过项），并单独显示当前文件的阶段进度。Whisper 的语音检测使用工具输出的已处理块数与总块数；字幕识别按最新片段结束时间与视频时长估算，明确显示“约”，不代表剩余耗时。智能分块可能反复进入语音检测，识别位置在同一文件内不倒退；识别估算最多显示 99%，不能据此判定字幕已生成。Jasna 解析命令行帧处理百分比、帧率和预计剩余时间；mkvmerge 使用 `--gui-mode` 输出封装进度。每个文件和工具调用独立重置，未知格式不猜测进度。

工作台展示阶段和文件完成数，任务队列进度条表示当前阶段，另列已完成文件数、处理速度及预计剩余时间。准备、等待工具反馈、校验、复制与回写没有可靠百分比时显示阶段文字和未定进度，不填充假百分比。工具输出 100% 只表示该阶段的报告值，文件仍需通过退出码、产物校验及收尾才计为完成。失败与取消保留停止阶段，不继续推进；页面刷新从主进程恢复状态。

进度行由主进程解析后写入状态，不逐帧写入运行日志，避免挤占错误与诊断记录；Whisper 已识别的时间戳行不重复记录字幕正文。其他工具输出与日志只在任务队列展示，内存保留最近 200 条。界面区分等待、运行、完成、失败、取消、跳过。工具失败停止当前链，后续步骤标记未执行；已有标记的文件跳过，不伪报工具处理成功。

工具日志过滤 ANSI 控制符，无法还原的混合编码按实际情况展示。任务队列展示输出和执行记录，不再展示恢复目录。

取消终止 Windows 进程树，复制和哈希在分块检查点响应；操作系统网络文件调用需等待其返回，不承诺即时取消。关闭窗口先请求取消并等待收尾，不在文件操作中直接退出。不执行真实关机。

`userData/pipeline/<任务 ID>.jsonl` 保存计划、步骤、提交与删除事件及结束状态；工具输出部分每次任务最多 2 MiB。任务详情中的输出位置是各步骤曾提交的位置，后续步骤可能已迁移这些文件。页面重载从主进程恢复当前状态，应用重启不自动重跑或续传。

## 验证边界

单元测试覆盖全四步、部分组合、单步选择、重名、文件变化、失败保留源、字幕和视频校验、MDC 伪成功、NAS 单向复制与大小不符、取消、预处理互斥及非法 IPC 参数。原生 Node 测试覆盖参数不经 shell、中文输出、退出码、超时与进程树取消。

桌面测试使用临时目录、文本媒体替身和编译的原生工具替身，真实经过预加载、IPC、主进程、外部进程和文件服务。另用人工生成的黑色视频与正弦音频核对本机 mkvmerge/ffprobe 的容器识别、封装及音轨/字幕保留行为。四种主题、最小/默认/最大化窗口、确认预览、单步、组合、四步、失败、取消和文件快照均列入桌面验收。

本机源码模型已在 CUDA 上加载，并使用合成正弦音频调用完整推理入口；静音类样本未产生字幕，不能据此判断真实字幕质量。MDC 7.7.2 已用隔离片段完成单次在线刮削；8.1.3 能启动并登录，但单次任务在登录后无进一步输出，目录模式与单文件模式均未完成。真实媒体批量、网络 NAS、安装包和签名仍未验证。没有运行参考项目脚本，没有删除用户原视频。最新测试结果见 [05 · 验证结果](05-验证结果.md)。
