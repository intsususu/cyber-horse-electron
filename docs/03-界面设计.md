# 03 · 界面设计说明

## 视觉方向

定位为个人日常使用的媒体工具。当前采用用户选定的第二版初号机方案：黑紫画布、紫色导航和步骤编号、荧光绿主操作。保留马头标识、清晰文字和柔和边框；不增加宣传语、装饰性主视觉或无效指标。

另保留暖白浅色、石墨深色与跟随系统。新配置默认初号机，已有偏好保持不变。状态同时包含文字或图标，不只依靠颜色。

## 信息与字级

| 用途                   | 字号 | 字重    |
| ---------------------- | ---- | ------- |
| 页面标题               | 28px | 650     |
| 面板标题               | 17px | 650     |
| 流程名称、主要运行按钮 | 16px | 600     |
| 正文、导航、文件名     | 15px | 450–650 |
| 表单、次要按钮、日志   | 14px | 450–550 |
| 状态、时间、性能摘要   | 13px | 450–550 |

使用系统中文无衬线字体，不下载字体。次级和辅助文字使用主题令牌；不通过整体透明度削弱可读性，不靠缩小文字容纳更多内容。

## 布局与窗口

默认窗口 1480 × 900，最低 1060 × 760。桌面侧栏按窗口取 194 / 228px，顶部窗口控制栏 32px，页面标题区紧接其下。窗口按钮贴合右上角，图标距离上边和右边一致。

页面左右和底部统一留白：默认及最大化为 24px，窄窗口为 18px；工作台的底部状态栏贴边由该页独立控制。面板标题栏统一为至少 60px，标题、正文和页脚共用 20px 内边距，窄窗口为 16px。长内容使用面板内滚动，底部操作区留在可视区域。

- 工作台：独立预处理使用轻量工具栏，次要按钮紧随名称；四步流程使用完整面板，标题和选中数量在左，主运行按钮在右，等宽步骤卡片在下。通过分组和按钮层级分开两个运行入口，移除悬空按钮行。文件清单和底部状态栏保持原有结构；检测中显示旋转与扫描线，目录和工具问题可点击定位配置项。工作目录默认预处理目录；性能趋势、工具详情和完整路径按需展开。
- 左侧导航：上方为工作台和媒体库；下方依次为任务队列和偏好配置。工作台集中提供独立预处理与后续四步处理，不再显示“标准流程”和“特殊任务”入口。
- 任务队列：集中展示任务和日志，支持局部滚动；其他页面不重复。
- 配置：合并路径与工具、字幕、媒体服务器、隐私封面四个分组。路径与工具内目录和工具入口并列；各分组局部滚动，共用底部“打开配置文件”和“保存配置”按钮。文件外部编辑后自动更新表单，无效内容在保存栏持续提示。
- 媒体库：提供 Emby 连接、媒体浏览与配置入口，服务不可用时显示明确状态。

正常桌面尺寸无整页滚动，文件、任务和日志分别局部滚动。最大化增加可视内容，不等比例放大控件。900px 以下浏览器或高倍缩放允许纵向回流。最小桌面窗口省略步骤间箭头，仍保留全部步骤名称与播放按钮。

## 交互约定

- 工作台和任务队列页头保留“运行说明”入口，说明真实处理范围；其余常驻功能解释移除。
- 提取清理并重命名独立执行，使用“开始预处理”文字按钮。四步横排、默认全选，名称和复选框控制是否参与；批量运行按钮置于四步流程面板标题行右侧，根据数量显示“运行全部 / 运行所选 N 步 / 请选择步骤”，按固定顺序运行选中步骤，与预处理按钮分开。每步播放按钮可独立运行，不改变组合；取消全部后不可批量运行，可“全选步骤”恢复。
- 默认“目录全部”并包含子目录。勾选文件切到“手动选择”；文件菜单可“仅选此文件”。清空后保持零项，禁止扩大范围。
- 点击工作目录名称打开对应文件夹，右侧紧邻刷新按钮；工作目录在“偏好配置”中更换，搜索按钮打开可筛选、分页的完整清单。
- 运行前扫描、启动时冻结文件清单；运行时禁用文件与步骤范围修改和重复启动，页头显示停止按钮。
- 运行、完成和取消状态位于步骤名称下方，不挤占文件区；详情集中在任务队列。
- 点击底部指标打开本机性能趋势，点击扳手查看工具状态。首次采样或不可用显示占位和真实原因。
- 路径可访问不等于工具可以执行；路径配置保持显式保存，主题即时保存。
- 首页检测只显示汇总与首个问题，具体原因也显示在对应配置项下；点击提示后输入框获得键盘焦点并滚动到可见位置。减少动画偏好下停用扫描、旋转和结果动效，仍保留检测状态文字。
- 所有图标按钮具有中文无障碍名称及提示；保留焦点轮廓、Esc 关闭和关闭后焦点恢复。全局页面搜索及 `Ctrl+K` 快捷键已移除，文件清单筛选保留。
- 动画遵循减少动画偏好；关机仅为倒计时演示。

## 验收

真实 Electron 中检查全部七页的初号机、深浅主题，以及跟随系统、最小窗口、最大化、流程完成与取消。最新布局记录见 `10-页面布局与底部对齐.md`，步骤交互见 `09-步骤选择与预处理入口.md`。完整读屏、高对比度和多档系统缩放仍属于发布前检查。
