# 11 · 统一配置与文件同步

日期：2026-09-27。

## 页面与操作

- 左侧下方的“偏好配置”入口统一管理路径、工具、字幕、媒体服务器和隐私封面，位于“任务队列”下方；其他页面的配置入口均指向该页。
- 页面分为路径与工具、字幕、媒体服务器、隐私封面四组；分组切换保留草稿，底部“保存配置”一次保存全部组。媒体服务器密码仍单独保存在系统安全存储。
- 媒体服务器分组增加可选的“JavBus 地址”，持久化为 `mediaServer.javbusUrl`；支持网站地址或示例详情链接，末尾番号在打开视频详情链接时替换。旧配置缺失该字段时默认留空，未配置则隐藏视频详情的对应图标。
- 媒体服务器分组提供“播放时默认静音”，保存为 `player.startMuted`，新旧配置缺失时均默认开启；每次打开播放器时应用，播放中可临时取消静音。已移除 MDC 工具日志目录配置；旧字段读取后自动清除，MDC 固定不生成工具文件日志。
- 开发界面热更新后，旧桌面后台可能仍拒绝新增字段。保存遇到该情况明确提示在任务结束后完整退出并重新打开应用，当前窗口保留草稿；不会把后台版本不一致误报为地址或文件权限错误。纯网站地址 `https://www.javbus.com` 可直接保存。
- 外观选项只在左下角选择，配置文件保留主题字段及原有选择。
- 底部“打开配置文件”用系统默认程序打开本应用固定的配置文件，不保存未提交草稿。首次打开创建默认文件，已有或损坏文件不被覆盖；打开失败显示中文提示。浏览器预览不提供本机文件打开能力。
- 工具标题区保留“检查已保存路径”；这只检查访问能力，不代表真实处理工具已可运行。
- 保存栏沿用普通页面底部留白，长表单只在面板内滚动，分类标签支持方向键、Home 和 End。

## 文件如何影响界面

主进程监听固定 `settings.json` 的文件状态，读取和写入串行处理，兼容编辑器使用临时文件替换保存。每次变更先验证字段与版本，再通过受限预加载订阅推送；运行时不重启页面。

文件变化的字段同步至当前配置、相关草稿、主题及工作台默认目录；未变化的字段保留表单中尚未保存的修改。保存前再次读取文件，避免将尚未同步的外部修改回写成旧值。左下角切换主题不会提交或清空其他表单草稿。

桌面窗口重新获得焦点或恢复可见时会重新读取配置，校准可能因热更新或错过推送而滞后的界面；读取响应按新旧顺序保护，旧请求不能覆盖后收到的配置变更。读取接口失败时保留当前内容并持续提示，重新进入窗口会重试，不再只显示短暂提示后留下空表单。

外部保存无效 JSON、无效字段，或暂时删除文件时，运行中的应用保持最近一次有效配置并提示。相同损坏内容不会因重复读取产生多个备份。修正文件后自动清除提示。切换主题不覆盖损坏文件；明确点击“保存配置”可以用有效表单修复文件。启动即无法读取时仍使用默认值并保留原文件。

窗口关闭时停止监听，页面卸载时移除订阅。未实现多个应用实例同时写配置的冲突协调。
