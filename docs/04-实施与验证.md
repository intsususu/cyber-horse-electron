## 阶段二：真实工作流

独立预处理及工作台四步已完成首轮迁移：专用主进程服务、冻结清单、工具适配器、取消及执行记录。预处理使用同卷快速移动，下载残留在移动成功后直接删除；字幕、视频与 MDC 产物使用 SHA-256 验证，NAS 归档仅比对文件大小且不回读文件内容。详见 `13-提取清理并重命名.md` 与 `14-四步真实处理.md`。以下为本阶段路线，文件服务和工具替身集成已实现，真实模型、在线 MDC 与网络 NAS 仍需实机验收；队列不跨重启自动恢复。

1. 设计主进程任务/子任务状态模型、持久化和事件订阅契约。
2. 建立目录扫描及非破坏执行计划，验证根目录保护、同名文件和网络中断。
3. 迁移文件整理与命名规则，以临时样本测试，禁止直接测试真实媒体库。
4. 接入 MDC 进程，处理退出码、编码、超时和取消。
5. 实现 NAS 单向复制、文件大小核对和整批成功后的直接清理策略。
6. 接入 Whisper、mkvmerge 和 Jasna；为每个工具建立适配器与替身测试。
7. 用真实任务事件替换 UI 模拟状态；移除对应“演示”标识前完成端到端验收。

## 验证策略

| 范围          | 验证方式                                                      |
| ------------- | ------------------------------------------------------------- |
| 演示状态机    | 串行完成、重复启动、取消后停止、运行中不能清空                |
| 配置          | 首次默认值、持久化、无效输入拒绝、损坏配置恢复、并发写入      |
| 路径          | 未配置、缺失、类型错误、可读目录和工具文件                    |
| Electron 集成 | 真实启动、预加载 API、进程隔离、配置保存与重启、主题与流程 UI |
| 视觉          | 深浅主题、默认/最小/最大化窗口、整页溢出、局部滚动与操作可达  |
| 依赖          | 类型检查、构建与依赖漏洞扫描                                  |

```powershell
npm run check
npm run test:desktop
npm run format:check
npm audit
```

桌面验证使用 `test-results` 下的隔离配置，不读取或修改用户真实配置。截图与测试输出被 Git 忽略。实际执行结果记录于 `docs/05-验证结果.md`；未执行的项目必须标记为未验证。
