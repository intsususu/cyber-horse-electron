# 13 · 提取清理并重命名

日期：2026-09-27。本次把独立预处理接入真实文件操作，随后工作台四步已按 `14-四步真实处理.md` 接入。原标准流程独立页面已移除。

## 业务规则

参考 `../cyber-horse/src/JavProcessDesktop/Services/StandardWorkflowService.cs` 及 `Models/WorkflowExecutionModels.cs`，只读取源码，不运行旧项目脚本、不读取其个人配置。

- 从已保存的下载目录递归提取 **至少 1 GiB（1024³ 字节）的所有普通文件**，包括非视频文件，平铺到已保存的预处理目录。此门槛与旧实现一致，并非提取所有小视频。两项目录必须已存在。
- 对提取的视频和预处理目录顶层的已有视频规范编号；沿用 2–6 个字母、2–6 个数字及 U/C/UC 标记，去掉末尾 restored 和可识别的站点前缀。例如 `prefix@abp-001-u_restored.mp4` → `ABP-001-U.mp4`。
- 无法识别编号的提取视频保留原名并提示；已有无法识别的视频不动。不推断多段编号、字幕配对或特殊编号；具体结果必须以预览清单为准。
- 同名采用 `_1`、`_2` 等递增后缀，已有文件与目录均不覆盖；已规范的冲突后缀名称重跑保持稳定。
- 所有提取与重命名成功后，才直接删除预览清单中小于门槛的普通文件，包括小视频、字幕和附件。大文件与已有视频直接移动到目标位置，不保留恢复副本。最后按从内到外的顺序移除预览列出的空下载子文件夹；下载根目录、有新文件的文件夹及预览后新增的文件夹保留，不递归清空目录。
- 新任务不创建 .cyber-horse-recovery 或 .cyber-horse-work。旧版本遗留目录与未完成中间文件只从扫描中排除，不自动迁移或删除历史文件。默认不触碰预处理目录子目录内的视频。

## 使用与执行记录

工作台“开始预处理”按钮打开预处理清单。清单展示来源、输出、操作类型、大小、将直接删除的下载残留和拟清理的空文件夹，每页 50 项；取消预览不写文件。点击“确认执行预处理”后实际执行，残留删除不保留副本。即使只剩空文件夹，也可再次预览并清理。浏览器预览不能执行。

预处理独立于后续步骤和文件选择；主进程负责执行与互斥。任务队列显示实际完成项数、当前操作、成功/失败/取消结果及执行记录。停止会终止后续项目；已完成移动与删除不自动撤销，尚未处理的文件留在原处。关闭窗口请求取消并等待当前文件操作收尾。

执行前将完整计划写入 `userData/preparation/<任务标识>.jsonl`，每项开始、目标路径建立、完成和最终状态都追加并刷新到磁盘。界面队列仍只保留本次会话，不自动恢复未完成任务。意外退出后可根据记录核对源目录、输出和输出目录；临时目录项以 `.cyber-horse-<标识>.partial` 识别，不自动清理无法确认归属的残留。

提取和重命名采用同卷移动，不生成独立备份。清单内残留直接删除，不提供撤销；异常中断后依据执行记录核对源目录和输出目录。

## 安全和契约

- 只接受已保存配置；拒绝空/相对/设备路径、磁盘根、用户根、系统目录、应用和参考项目目录、下载与预处理重叠。检查路径各级目录，拒绝符号链接与目录联接，并解析 Windows 短路径。
- 扫描最多各 5000 个下载文件与顶层视频、100000 个目录项，协作式扫描限时 20 秒。不可读或链接项目导致预览失败，不返回可执行的不完整范围。
- 计划有效期 10 分钟，只保留最近一份；渲染端只回传 UUID。启动时复核配置、文件身份/大小/时间与目标占用；每项执行前再次复核。新增文件不纳入本次清理，源文件变化会停止。
- 下载与预处理目录必须位于同一卷。先为源文件独占创建临时硬链接，再独占建立目标路径；核对文件身份、大小与修改时间并写入执行记录后，才移除原路径。这个过程不复制或通读文件内容，文件大小不再决定移动耗时。目标已存在、校验失败或取消时保留尚未移动的源文件；已经完成的项目不自动撤销。
- 空文件夹清理只针对预览时扫描到的下载子目录，逐个验证路径和目录身份后调用非递归移除；文件夹非空、被替换或已经变化时保留，绝不删除下载根目录。文件移动未全部成功时不开始残留删除或文件夹清理。
- 文件系统必须支持硬链接（本轮验证 Windows 本地 NTFS）；跨卷或不支持时安全失败，不退回覆盖目标或复制大文件的方式。NAS、网络盘和其他文件系统未验证。
- 每项移动前及移除源路径前检查取消；等待操作系统文件操作时无法承诺立即中断。崩溃、拔盘或外部程序同时修改目录不属于自动回滚保证。
- 专用接口：`previewPreparation()`、`startPreparation({ planId })`、`getPreparationState()`、`cancelPreparation()`。均验证主窗口来源；预加载不导入 Zod 等运行时依赖，不暴露任意文件或命令能力。
