# Cyber Horse · Electron

以本地媒体处理工作流为核心的桌面应用。参考同级 `cyber-horse` 的业务能力，使用 Electron、React 和 TypeScript 重新构建。

当前为 **v0.1.0 开发预览**：桌面工作台、四种主题、路径设置与检查，以及真实的提取清理并重命名。工作台字幕、视频处理、刮削与 NAS 归档已接入真实执行服务；Emby 媒体库已接入，系统关机仍为演示。外部模型及在线服务仍待实机验收。

## 启动并查看界面

环境：Windows 10/11、Node.js 22.12+（推荐 Node.js 24 LTS）、npm。

在本项目根目录（包含 `package.json` 的目录）打开 PowerShell。首次运行先安装依赖：

```powershell
npm ci
```

查看完整桌面界面，运行：

```powershell
npm run dev
```

命令启动后会自动打开 Electron 窗口。修改界面代码时，开发窗口会自动更新；保持 PowerShell 窗口运行，结束时按 `Ctrl+C`。

修改主进程、预加载桥接或共享配置格式后，需要在任务完成后完整退出并重新执行 `npm run dev`；界面热更新不会更新已经运行的桌面后台。新增配置项若被旧后台拒绝，表单会保留输入并提示重新打开应用。

如果只想在浏览器中快速查看界面，运行：

```powershell
npm run dev:web
```

然后在浏览器打开 `http://127.0.0.1:5173`。浏览器预览使用独立的本地存储；原生目录选择、预处理和桌面集成请使用 `npm run dev`。桌面工作台提供独立预处理与四步真实处理。

## 打包为独立 EXE

在 Windows 的项目根目录打开 PowerShell，首次打包先执行 `npm ci`，然后运行：

```powershell
npm run dist:portable
```

脚本会先检查类型并构建，再生成 Windows x64 免安装单文件程序：`release/Cyber-Horse-0.1.0-x64-portable.exe`（文件名中的版本号随项目版本变化）。复制这个 EXE 到目标 Windows 电脑后即可双击启动，无需安装 Node.js、npm 或 Electron，也无需保留项目源码。首次打包需要联网下载 Electron 和打包工具。

免安装程序运行时会自动解压到临时目录；配置仍保存在本机用户数据目录，不随 EXE 一起移动。媒体处理所需的 Whisper、模型、mkvmerge、Jasna、MDC 等外部工具不会一并打包，需要在目标电脑单独准备并配置路径。当前打包清单包含本机 `config/default-settings.json`（如存在）和 `assets` 资源，对外分享前应检查其中是否包含个人路径、服务器资料或凭据。

如需安装向导，运行 `npm run dist`，输出为 `release/Cyber-Horse-0.1.0-x64.exe`。`npm run pack` 只生成解包目录，必须保留整个目录，不能仅复制其中的 EXE。当前未配置代码签名；生成文件不代表已完成目标电脑运行、安装升级或签名验证。

## 命令

| 命令                    | 用途                                           |
| ----------------------- | ---------------------------------------------- |
| `npm run dev`           | 启动 Electron 并启用界面热更新                 |
| `npm run dev:web`       | 在浏览器中预览界面                             |
| `npm run check`         | 类型检查、行为测试与生产构建                   |
| `npm run test:desktop`  | 启动真实 Electron，验证桥接与交互并保存截图    |
| `npm run build`         | 构建主进程、预加载和页面到 `out`               |
| `npm run preview`       | 启动生产构建                                   |
| `npm run pack`          | 生成未签名的解包桌面程序到 `release`           |
| `npm run dist`          | 生成 Windows NSIS 安装包，正式分发前需配置签名 |
| `npm run dist:portable` | 生成 Windows x64 免安装单文件 EXE 到 `release` |
| `npm run format`        | 统一代码和文档格式                             |

如果依赖安装器限制安装脚本，Electron 运行文件可能没有下载。可在确认来源后执行 `node node_modules/electron/install.js`，再重新启动。无需全局安装 Electron。

## 项目结构

```text
config/                  开发工具配置
src/
  main/                  主进程和本地服务
    services/            配置存储、路径检查
  preload/               受限的桌面能力桥接
  shared/                跨进程类型、通道与校验
  renderer/src/
    components/          页面与可复用界面
    data/                功能目录和导航定义
    hooks/               工作空间状态与交互
    lib/                 任务状态与进度展示
    styles/              主题令牌与页面样式
tests/                   核心行为测试
scripts/                 桌面集成验证
docs/                    功能、架构、视觉与实施说明
```

## 当前可以体验

**项目内默认配置：[config/default-settings.json](config/default-settings.json)。** 这里保存本机提供的完整配置（原字段格式）；正常启动自动用于初始化新配置和旧的全空配置，已有自定义配置保留。该本机文件已加入 Git 忽略。运行期间的保存和“打开配置文件”仍操作用户数据目录中的配置。

- 左侧上方提供工作台与 Emby 媒体库；下方依次为任务队列和偏好配置。
- 工作台独立预处理、后续四步单步、部分组合或全部真实处理；默认载入预处理目录全部视频，支持单选、多选和运行前刷新；任务和日志集中在“任务队列”页，可停止、筛选及导出。
- 独立预处理先预览确认，再同卷快速移动至少 1 GiB 的文件、规范视频编号；下载残留在移动成功后直接删除，空下载子文件夹随后移除。支持重名保护、移动校验、取消和失败停止；提取和重命名不保留独立恢复副本，详见 [预处理规则](docs/13-提取清理并重命名.md)。
- 真实目录与文件选择，支持全部视频、单选、多选、子目录、文件名筛选。
- 底部 CPU、GPU、内存、网络真实采样，点击展开近期趋势；未获得采样时明确显示状态。
- 系统原生路径选择、独立配置持久化、非执行式路径可访问性检查。
- 初号机及深浅主题即时切换与持久化，跟随系统实时更新。
- `Ctrl+K` 搜索页面；弹窗支持 `Esc` 关闭和键盘焦点管理。
- 关机倒计时交互演示，不会调用系统关机。
- 默认 1480 × 900 窗口同屏查看流程、文件与本机状态，支持最大化；采用清晰字级、初号机紫绿主题及中性深浅主题，长列表在面板内滚动。

配置默认路径：`%APPDATA%/cyber-horse-electron/settings.json`，以 Electron 的 `userData` 实际位置为准。首次启动优先加载项目内默认配置；没有默认文件时才使用空值。统一配置页支持路径与工具、字幕格式、媒体服务器资料、隐私封面，底部统一保存或打开配置文件。文件外部保存后自动校验并同步界面，无效内容保留上一次有效设置；主题仅在左下角选择。密码使用本机系统安全存储。现有版本 1 设置会自动升级并保留路径和主题，不读取参考项目的个人配置。媒体服务器连接、分页筛选、详情收藏、下载、隐私封面和详情复合处理已实现，详见 [Emby 媒体库](docs/15-Emby媒体库.md)。工作台四步先预览，再调用所需工具；字幕和视频处理需要工具目录中的 ffprobe，详见 [四步真实处理](docs/14-四步真实处理.md)。队列界面、会话日志和倒计时仅保留在本次会话中；预处理和四步处理另存执行记录，成功处理后直接删除对应旧文件，不保存恢复副本。
